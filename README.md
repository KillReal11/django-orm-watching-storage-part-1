# Пульт охраны банка

Это внутренний репозиторий для сотрудников банка "Сияние". Если вы попали в этот репозиторий случайно, то вы не сможете его запустить, т.к. у вас нет доступа к БД, но можете свободно использовать код верстки или посмотреть как реализованы запросы к БД.

Пульт охраны - это сайт, который можно подключить к удаленной базе данных с визитами и карточками пропуска сотрудников банка.

### Как установить

Для подключения к базе данных, нужно заполнить данные в файле [settings.py](settings.py).
Такие данные, как, например, пароль бд и секретный ключ сайта являются чувствительными и должны быть скрыты. Для этого используются переменные окружения, которые прячут значения чувствительных данных в отдельном `.env` файле.

Python3 должен быть уже установлен. 
Затем используйте `pip` (или `pip3`, есть конфликт с Python2) для установки зависимостей:
```
pip install -r requirements.txt
```
### Пример запуска 

Запуск осуществляется командой в терминале `python main.py`.
